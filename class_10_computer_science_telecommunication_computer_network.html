2. Telecommunication / दूरसञ्चार

Etymology / उत्पत्ति

Tele + Communication

Derived from the Greek word 'Tele' (meaning distant or far off) and Latin 'Communicare' (to share). It is the exchange of information over significant distances by electronic or electromagnetic means.

ग्रीक शब्द 'Tele' (जसको अर्थ टाढा हुन्छ) र ल्याटिन शब्द 'Communicare' (साझेदारी गर्नु) बाट बनेको हो। इलेक्ट्रोनिक वा इलेक्ट्रोम्याग्नेटिक माध्यमबाट टाढा-टाढा सूचना आदानप्रदान गर्ने प्रविधिलाई दूरसञ्चार भनिन्छ।

4. Transmission Media / प्रसारण माध्यम

Guided Media (Wired / तारयुक्त)

Physical solid cables that carry data signals along a contained path.

भौतिक तारहरू जसले निश्चित मार्गबाट डाटा सङ्केतहरू लैजान्छन्।

Twisted-Pair Cable (UTP/STP) RJ-45

Used in LANs & landline telephones. Inexpensive, easy to install.

Coaxial Cable BNC

Used in Cable TV networks in Nepal. Good shielding against interference.

Fiber Optic Cable (फाइबर अप्टिक) Light Signals

Uses total internal reflection of light. Highest speed (FTTH internet in Nepal like WorldLink, NT Fiber).

Unguided Media (Wireless / ताररहित)

Electromagnetic waves transmitted through air, space, or water.

हावा वा अन्तरिक्ष मार्फत प्रसारण हुने इलेक्ट्रोम्याग्नेटिक तरङ्गहरू।

Radio Waves

Omnidirectional (FM radio, Wi-Fi, 4G/5G mobile networks).

Microwaves

Line-of-sight propagation (dish antennas on mobile towers).

Infrared & Satellite

Infrared for TV remotes; Satellites for long-distance global broadcasts.

5. Computer Network / कम्प्युटर नेटवर्क

Formal Definition / परिभाषा

A computer network is an interconnected group of autonomous computers and computing devices connected via transmission media to share resources (files, printers) and communicate.

कम्प्युटर नेटवर्क भनेको आपसमा जोडिएका स्वतन्त्र कम्प्युटर र उपकरणहरूको समूह हो, जसले डाटा, सूचना तथा स्रोतहरू (जस्तै: प्रिन्टर, इन्टरनेट) साझा गर्न सक्छन्।

Key Benefits / मुख्य फाइदाहरू:

  • Hardware Sharing (One printer for whole lab)
  • Software & File Sharing
  • Centralized Data Storage & Backup
  • Instant Communication (Email, Chat)

9. Network Architecture / नेटवर्क संरचना

1. Client-Server Architecture

A centralized system where powerful computers (Servers) store files and respond to requests from user workstations (Clients).

केन्द्रीकृत प्रणाली जहाँ शक्तिशाली कम्प्युटर (सर्भर) ले डाटा भण्डारण गर्छ र क्लाइन्ट कम्प्युटरको अनुरोध पूरा गर्छ।

Advantages:
• Centralized backup & high security.
• केन्द्रीकृत ब्याकअप र उच्च सुरक्षा।

2. Peer-to-Peer (P2P) Architecture

All computers on the network have equal capabilities and responsibilities. There is no dedicated central server.

सबै कम्प्युटरहरूको समान क्षमता र अधिकार हुन्छ। यहाँ कुनै छुट्टै मुख्य सर्भर हुँदैन।

Advantages:
• Easy to setup, low cost for small homes/offices.
• साना घर/कार्यालयमा स्थापना गर्न सजिलो र कम खर्चिलो।

11. Network Protocols / सञ्चार नियमावली

TCP/IP

Transmission Control Protocol / Internet Protocol. The fundamental rules governing the global Internet.

HTTP / HTTPS

Hypertext Transfer Protocol (Secure). Used for fetching web pages securely with SSL encryption.

FTP

File Transfer Protocol. Specialized rules for uploading and downloading large files between devices.

DNS

Domain Name System. Translates human-friendly names (e.g., google.com) into IP addresses (142.250.x.x).

12. Advantages & Disadvantages / फाइदा तथा बेफाइदाहरू

Advantages (फाइदाहरू)

  • Resource Sharing: Share expensive printers, scanners & storage.
  • Fast Communication: Instant emails, voice calls & videoconferencing.
  • Centralized Data: Data saved centrally for easier backups.
  • Cost Efficiency: Reduces paper, printing, and hardware expenses.

Disadvantages (बेफाइदाहरू)

  • Security Risks: Viruses, malware, and hacking threats.
  • Server Dependency: Main server failure halts whole network.
  • Setup Cost: High initial investment for cables, switches, routers.
  • Maintenance: Requires skilled network administrators.

  • 38-45 Min: Q&A, Homework assignment & Lesson wrap-up.

Common Misconceptions to Clarify:

• Hub vs Switch: Clarify that a Hub broadcasts data to all ports (insecure), while a Switch forwards data specifically to the destination MAC address.

• Modem vs Router: A Modem modulates/demodulates ISP signals, while a Router directs data traffic between separate networks.
